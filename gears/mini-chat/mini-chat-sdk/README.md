# cf-gears-mini-chat-sdk

SDK of the `mini-chat` gear: the model-policy and audit plugin contracts
(`MiniChatModelPolicyPluginClientV1`, `MiniChatAuditPluginClientV1`), their GTS
plugin specs, and the shared types (`PolicySnapshot`, `ModelCatalogEntry`,
`KillSwitches`, `UserLimits`, `UsageEvent`, audit events).
