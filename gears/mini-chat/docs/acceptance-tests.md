# Acceptance Tests: Mini Chat

This document traces every item of [acceptance-criteria.md](./acceptance-criteria.md)
to the automated tests that cover it. Each row has one criterion and the tests that
cover it.

## Notation

- `tests/x.rs::name` is an integration test in `gears/mini-chat/mini-chat/tests/`. It
  runs the REST/SSE API in process against the scripted fake provider of
  `mini_chat::testing` and a real SQLite DB.
- `src/…/x_tests.rs::name` is a unit test next to its module, in
  `gears/mini-chat/mini-chat/src/`.
- `sdk:models_tests.rs::name` is a unit test of `gears/mini-chat/mini-chat-sdk`.
- `smoke §N` is step N of the black-box smoke test
  `gears/mini-chat/e2e-smoke/run_smoke.py`. Its steps are listed in
  [e2e-smoke/README.md](../e2e-smoke/README.md#what-is-checked-per-flavour). It runs the
  real `cf-gears-example-server` through api-gateway and OAGW against the mock
  provider, once with the `openai` flavour and once with the `azure` flavour.

## Commands

```bash
cargo test --offline -p cf-gears-mini-chat-sdk -p cf-gears-mini-chat
python3 gears/mini-chat/e2e-smoke/run_smoke.py
```
