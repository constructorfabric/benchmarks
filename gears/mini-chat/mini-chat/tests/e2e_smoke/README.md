# mini-chat black-box smoke suite

pytest suite that drives a real `cf-gears-example-server` (mini-chat gear) over HTTP/SSE against a
local mock OpenAI provider, and inspects the gear's SQLite database read-only.

## Run

```bash
./run_smoke.sh               # cargo build of the server binary, then pytest
./run_smoke.sh --no-build    # reuse target/debug/cf-gears-example-server
./run_smoke.sh --no-build -m "not slow"   # skip the ~25 s indexing-deadline test
```

Requirements: Python 3 with `pytest`, `requests`, `PyYAML`; nothing else (no network beyond localhost).

Ports: API `28086`, mock provider `28999` (override with `MC_E2E_API_PORT` / `MC_E2E_MOCK_PORT`).
The suite refuses to start if a port is already in use. Binary: `MC_E2E_BIN` (default
`target/debug/cf-gears-example-server`).

## How it works

- `conftest.py` starts `mock_provider.py` and the server with `subprocess.Popen` (stopped through
  those objects only), using a config generated by `make_config.py` into a fresh
  `/tmp/mc-e2e-*/home-*` dir (fresh database). It waits for `/health` = 200 and for
  `OAGW upstream provisioned provider=mock` + `mini-chat gear started` in the server log.
  Logs, configs and the DB stay in the `/tmp/mc-e2e-*` dir for debugging.
- A test module can set `VARIANT = "<name>"` (see `VARIANTS` in `conftest.py`); the server is
  restarted with that config only when the variant changes:
  - `default`: SSE ping interval 5 s, OAGW proxy timeout 30 s.
  - `limits`: `rag.uploaded_file_max_size_kb=4`, kill switches `disable_web_search` and
    `disable_images`, premium daily limit 5000 credits (forces a downgrade), OAGW timeout 2 s.
  - `exhausted`: total daily limit 5000 credits (every turn rejected with 429).
  - `websearch`: `quota.web_search_daily_quota=1`.
- `mock_provider.py` behaviour is selected by markers in the last user message (`[[error]]`,
  `[[429]]`, `[[500]]`, `[[web_search]]`, `[[web_search3]]`, `[[file_search]]`, `[[slow]]`,
  `[[stall]]`, `[[incomplete]]`, `[[empty]]`); `GET /_mock/requests`, `POST /_mock/reset`,
  `POST /_mock/config` (`index_status`, `file_upload_status`, `stall_secs`).
- Helpers: `Client` (per token: `e2e-token-tenant-a`, `-reviewer`, `e2e-token-tenant-b`),
  `sse_request` / `iter_sse` (SSE parser), `background_stream` (turn running in a thread),
  `assert_problem` (RFC 9457 canonical errors), `DB` (sqlite3 read-only, UUIDs as 16-byte BLOBs),
  `MockCtl`.

## Files

| File | Covers |
|---|---|
| `test_chats.py` | chat CRUD, title/model validation, list OData (`$filter`, `$orderby`, `limit`, `cursor`), errors |
| `test_streaming.py` | SSE order and payloads, provider request body, replay, 409 conflicts, provider errors, web search, ping, disconnect -> cancelled |
| `test_messages_turns.py` | messages list, turn status, reactions, retry / edit / delete |
| `test_models_quota.py` | models API, quota status, quota accounting, outbox usage / audit events |
| `test_attachments.py` | upload / get / delete, Files + Vector Stores calls, thumbnails, file_search, images, code interpreter files, deletion guard, chat-deletion cleanup |
| `test_authz.py` | other user / other tenant get 404 everywhere |
| `test_variant_exhausted.py` | quota exhausted -> 429 before the stream |
| `test_variant_limits.py` | FILE_TOO_LARGE, kill switches, premium downgrade, OAGW idle timeout mid-stream |
| `test_variant_websearch.py` | daily web search quota -> 429 `web_search` |
| `test_zz_startup.py` | requests during server start (xfail: known product bug) |

## Known issues / not covered

- `test_chats.py::test_list_filter_timestamp_exact` and
  `test_messages_turns.py::test_messages_filter_timestamp_exact` are `xfail`: on SQLite a `$filter`
  on `updated_at` / `created_at` with the exact value returned by the API does not match with `eq`,
  and `gt` includes the row with that value.
- `test_variant_limits.py::test_provider_idle_timeout_mid_stream` accepts `provider_error` or
  `provider_timeout`: an OAGW read timeout after the stream started currently surfaces as
  `provider_error` ("Provider stream ended without a terminal event").

- `test_zz_startup.py` is `xfail`: a write request that reaches mini-chat while the gear is still
  starting can make the outbox start fail (`database is locked`, SQLite code 517) and the server
  exits.
- Not covered black-box (would need long waits or fault injection): orphan watchdog (timeout >= 90 s),
  upload reaper (stale_after >= 60 s), thread summary generation, PDP failures (503), license gate,
  provider-mismatch (409), per-chat document/storage limits, `finalization_failed` /
  `message_persistence_failed`.
