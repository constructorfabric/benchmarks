# Mini Chat Gear + SDK Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Implement the `mini-chat` gear (multi-tenant AI chat with SSE streaming, attachments, quotas, turn mutations, thread summaries, outbox-driven cleanup/usage/audit, recovery workers) and its SDK crate so the example server satisfies `gears/mini-chat/docs` and every item of `acceptance-criteria.md`.

**Architecture:** DDD-light gear: `api/rest` (handlers, DTOs, error mapping, SSE) → `domain` (services, ports, pure algorithms) → `infra` (SeaORM secure repos + migrations, LLM adapters over OAGW, OAGW provisioning, platform outbox + handlers, workers, bundled static plugins). The SDK crate holds the plugin contracts and shared payload types.

**Tech Stack:** Rust 2024, toolkit gear framework, axum 0.8, utoipa 5, SeaORM 2 (SQLite + Postgres), toolkit-db secure ORM + outbox, toolkit-odata, toolkit-canonical-errors, authz-resolver-sdk (PolicyEnforcer), authn-resolver-sdk (S2S), oagw-sdk (ServiceGatewayClientV1), types-registry-sdk, image (WebP thumbnails), multer; Python 3 + pytest for the black-box suite.

**Spec:** `docs/superpowers/specs/2026-10-04-mini-chat-gear-design.md` (which points to the normative contract in `gears/mini-chat/docs/{DESIGN.md,PRD.md,ADR/*,acceptance-criteria.md}` and `docs/api/api.json`).

## Review Focus

1. Two concurrent `messages:stream` requests on one chat (different `request_id`s): exactly one gets the SSE stream, the other gets 409 `aborted` `turn_already_running` (unique-index race mapped, never 500). Test owned by Task 13.
2. Client disconnects mid-stream: no SSE `error` is attempted, the turn ends `cancelled`, partial text is persisted as the assistant message when non-empty, quota settles `estimated` and one usage event with `billing_outcome = "aborted"` is enqueued. Test owned by Task 13.
3. Messages created within the same second (fast turns): `GET /messages` stays chronological and cursors are stable on SQLite. Test owned by Task 8 (uses `db_ts`).
4. Provider error text containing `resp_…`, `file-…`, `vs_…`, URLs, `sk-…` keys or `Bearer` tokens: the SSE `error.message` and REST `detail` show `[provider_id]`, `[url]`, `[credential]` instead. Test owned by Task 10b (adapter) and Task 13 (end-to-end SSE).
5. Server restart over an existing DB (migrations idempotent, outbox partition count unchanged, upstreams re-provisioned, running turns later finalized by the watchdog). Test owned by Task 19 (e2e restart test).
